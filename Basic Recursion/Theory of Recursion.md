Recursion is a programming technique in which a function calls itself to solve a smaller version of the same problem.
* We keep breaking the problem into smaller problems until we reach a condition where we already know the answer.That is recursion.
* Whenever you solve a recursion problem, understand these three things.
 A. Base condition
 * The base condition tells recursion when to stop.
 * Without a base condition, the function keeps calling itself until Java runs out of stack space.
 B. Recursive call
 * A recursive call means calling the same function again with a smaller or simpler input.
 C. Return value
 * The return value is the answer passed back to the previous function call.


4-step approach to solve recursion
1. Identify the smaller problem
2. Find the base condition
   
3. Write the recursive call
   
  
4. Decide what to return
